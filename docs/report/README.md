# Пояснювальна записка: як оформити PDF

Текст записки — `explanatory-note.md` (українською, п'ять розділів за вимогами
завдання + Додаток А з промптами). Завдання вимагає подати звіт у форматі PDF разом з
посиланням на репозиторій.

## Як отримати PDF

Варіант 1, Pandoc (потрібні `pandoc` і LaTeX-рушій з підтримкою кирилиці):

```bash
cd docs/report
pandoc explanatory-note.md -o explanatory-note.pdf \
  --pdf-engine=xelatex -V mainfont="DejaVu Serif" -V monofont="DejaVu Sans Mono" \
  -V geometry:margin=2.5cm --toc
```

Варіант 2: відкрити `explanatory-note.md` у редакторі з підтримкою Markdown
(наприклад, VS Code з розширенням Markdown PDF) і експортувати у PDF; або вставити
текст у Word / Google Docs і зберегти як PDF (так зручніше додавати рисунки й титульний лист).

Місця для рисунків і таблиць у записці позначено «[ЗАПОВНИТИ …]». Pandoc і більшість
редакторів не відображають діаграми Mermaid, тому їх треба експортувати у зображення:

```bash
npm install -g @mermaid-js/mermaid-cli
# збережіть кожен блок ```mermaid з docs/uml/README.md у окремий файл d1.mmd, d2.mmd ...
mmdc -i d1.mmd -o d1.png -s 2
```

Або відкрийте `docs/uml/README.md` на GitHub, де діаграми відображаються, і зробіть знімки.
